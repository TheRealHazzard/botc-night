# Character art

Drop image files here named after the character id, e.g. `washerwoman.png`.
Accepted extensions: png, jpg, jpeg, webp, gif, svg, avif.

This folder is gitignored (except this file). Anything missing falls back to
the plain text treatment automatically, so a partial set is fine. New files are
picked up without restarting the server.

Round images work best — they are rendered as circles.
