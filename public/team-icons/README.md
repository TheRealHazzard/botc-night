# Team badges

Drop a badge image here named after the team: `townsfolk.png`, `outsider.png`,
`minion.png`, `demon.png`. Accepted extensions: png, jpg, jpeg, webp, gif, svg, avif.

This folder is gitignored (except this file). Used as the small corner badge
on a revealed player's token on the host's reveal screen — missing badges
just don't show, so a partial set is fine.
